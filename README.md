# trustgate-pr-test
TrustGate PR 앱의 승인 댓글, 격리 보안 테스트, Check Run 및 읽기 전용 MCP 검증을 위한 테스트 저장소입니다.

## 격리 검사용 합성 상점

이 PR은 결제와 주문 조회를 제공하는 의도적으로 취약한 교육용 HTTP 서비스를 추가합니다. 모든 계정·잔액·세션·배송지는 합성 데이터입니다. 프로덕션 인증이나 실제 결제는 포함하지 않습니다.

실행과 테스트는 TrustGate의 작업 컨테이너 안으로 제한합니다. 이 서비스를 공개 네트워크에 배포하거나 개인 호스트에서 실행하지 않습니다. 내부 서비스 주소는 worker 내부 `127.0.0.1:18080`이며 호스트 포트를 게시하지 않습니다.

- 승인된 범위: 이 PR head SHA의 상점 소스만 검사합니다.
- 정상 동작: 상품 조회, 카탈로그 가격 구매, 본인 주문 조회입니다.
- 검사 목표: 정상 동작과 비교해 결제·접근 제어의 이상을 실제 실행으로 확인합니다.
- 결과 해석: 기본 테스트 통과는 보안 통과가 아닙니다. 근거가 없거나 실행이 실패하면 미확인으로 보고합니다.
- 변경·정리: 원본 소스는 수정하지 않고 실행 근거를 회수한 뒤 소유 작업 환경을 정리합니다.

합성 세션 식별자는 `alice-demo-session`, `bob-demo-session`이며 실제 자격 증명이 아닙니다. 의존성 설치 없이 Node.js 24에서 실행할 수 있습니다. `Containerfile`은 컨테이너 내부 빌드용이고 `shop.test.mjs`는 정상 동작 대조군입니다.
